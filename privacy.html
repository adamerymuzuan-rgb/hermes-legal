Privacy Policy

TARS Hermes (personal application) · Effective 7 November 2026

This policy explains what happens to data when the TARS Hermes application (the "App") is authorised to access a Google Account. The App is a private, single-user tool built and operated by one individual for their own use. It is not offered to the public and has no other users.

In one line: the App reads and writes only the operator's own Google data, stores everything on that person's own computer, and shares it with nobody.

3. Where data is stored

  • Locally, on the operator's own computer. No application server, cloud database or hosted backend exists for this App.
  • An OAuth refresh token is stored in a local file (google_token.json) readable only by the operator's user account.
  • Working data (summaries, drafts, logs) is written to local files and a local SQLite database on the same machine.
  • Nothing is uploaded to any infrastructure controlled by the operator beyond the user's own device.

4. Sharing and third parties

  • No sale, rental or sharing of Google user data with advertisers, data brokers or any third party.
  • Requests are sent directly from the operator's computer to Google's APIs. The only other recipients of content are the AI model providers the operator has configured, and only for the text needed to complete a request the owner asked for. These providers are used under their own API terms and do not receive Google account credentials.
  • Google user data is not used to train or improve any generalised or non-personalised AI/ML model by the operator.
  • No human other than the operator reads the data.

5. Retention and deletion

  • Data stays on the device until the operator deletes it — per-item deletion is available at any time.
  • Revoking access: visit myaccount.google.com/permissions and remove TARS hermes. Access stops immediately; the stored token becomes useless.
  • Deleting google_token.json and the local data directory removes all retained data.

6. Security

  • Transport to Google uses HTTPS only.
  • The OAuth token is stored on a single device, protected by the operating system account and full-disk encryption where enabled.
  • The operator's Google Account is protected with two-factor authentication.
  • No credential is transmitted to, or stored by, any third party.

7. Limited Use statement

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children

The App is not directed at children and is not used by anyone other than its single adult operator.
