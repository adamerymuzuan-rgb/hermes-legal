# TARS Hermes — Legal Pages

Public privacy policy and terms of service for **TARS Hermes**, a private single-user
automation tool operated by Adam Ismail bin Erymuzuan.

These pages are published **only** to satisfy Google's OAuth branding requirement, which
mandates a publicly reachable privacy policy URL for apps requesting access to Gmail,
Calendar or Drive.

| Page | URL |
|---|---|
| Home | https://adamerymuzuan-rgb.github.io/hermes-legal/ |
| Privacy Policy | https://adamerymuzuan-rgb.github.io/hermes-legal/privacy.html |
| Terms of Service | https://adamerymuzuan-rgb.github.io/hermes-legal/terms.html |

## What this repo contains

- `index.html` — landing page with the key facts
- `privacy.html` — what Google data is accessed, where it lives, how to revoke
- `terms.html` — personal use, as-is, Malaysian jurisdiction

Static HTML only. No JavaScript, no cookies, no analytics, no trackers, no external fonts.

## Google OAuth scopes covered

`gmail.readonly`, `gmail.send`, `gmail.modify`, `calendar`, `drive`,
`contacts.readonly`, `spreadsheets`, `documents`
